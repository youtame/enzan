# イントロダクション

![Main visual](/assets/main.png)

普段通勤や通学、レジャーや旅行で鉄道を利用する人は多いのではないでしょうか。このSite for Trainは鉄道にそこまで興味がない人でも鉄道に関して詳しく知っていただくためにスタートしたブログ記事です。4人の筆者が別々の角度から鉄道に関する雑学や知って損しない楽しい情報を、このブログを通じて紹介します!

::: tip ご案内
さっそく記事を読みたい方は[こちら](./article/index)
:::

## 列車に乗っているとき

列車に乗っているとき、見渡してみるとだいたい90%程度の人が携帯電話を見ていることでしょう。　どうしよう、何も携帯電話でやることがない。　そんなときは[Site for Train](./)の出番でしょう。　列車に関する豆知識やどうしようもない記事がもりだくさんです。

## 信号待ちのとき

どうしよう、散歩中に信号に引っかかってしまった。　この信号青になるまでにかなり時間がかかるんだよな...　そんなときは[Site for Train](./)の出番でしょう。　最短45秒で読める記事が盛りだくさん。　あなたのスキマ時間をしっかりと支えます。

## 鉄道の知識をつけたいとき

鉄道に関してもっと知見を深めたい...　そんなときは[Site for Train](./)の出番でしょう。　週２日で気軽に定期読みができるから便利。　短い記事でしっかりとした知識を得ることができるでしょう。
