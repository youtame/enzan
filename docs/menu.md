# イントロダクション

![Main visual](/assets/main.png)

日本人にとって生活に特に密着している交通手段の一つである鉄道。　鉄道愛好家が多いことは特に知られているが、果たして鉄道に興味を持ったことがない人はどれくらい鉄道に関して知っているのだろうか。　　このSite for Train(鉄道のためのサイト)を機に少々鉄道に関して深堀するのはいかがだろうか。　週２回の更新で登竜門として間違いないだろう。　早速鉄道の世界へ出発進行！

## このサイトが役に立つタイミング

- **列車に乗っているとき**

列車に乗っているとき、見渡してみるとだいたい90%程度の人が携帯電話を見ていることでしょう。　どうしよう、何も携帯電話でやることがない。　そんなときは[Site for Train](./)の出番でしょう。　列車に関する豆知識やどうしようもない記事がもりだくさんです。

- **信号待ちのとき**

どうしよう、信号に引っかかってしまった。　この信号変わるまでにだいたい3分くらいかかるんだよな...　そんなときは[Site for Train](./)の出番でしょう。　最短45秒で読める記事が盛りだくさん。　あなたのスキマ時間をしっかりと支えます。

- **鉄道の知識をつけたいとき**

鉄道に関してもっと知見を深めたい...　そんなときは[Site for Train](./)の出番でしょう。　週２回という中途半端な更新だから、続けるのが苦手なあなたにでも大丈夫。　短い記事でしっかりとした知識を得ることができるでしょう。
