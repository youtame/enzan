## プライバシーポリシー

このプライバシーポリシーは、当サイト（[https://youtame.github.io/enzan](https://youtame.github.io/enzan)）におけるユーザーの個人情報の取り扱いについて説明するものです。ユーザーは、当サイトを利用するにあたり、必ずこのポリシーをご覧いただく必要があります。

### 個人情報に関して

1. 当サイトでは、ユーザーのIPアドレスを取得し、地域別に統計データを収集することがあります。
2. 当サイトで取得した個人情報は、サービスの改善のために利用します。
3. 当サイトで取得した情報は、102do 合同会社（以下「当社」）以外の第三者に提供することはありません。ただし、法令に基づく場合を除きます。
4. 当サイトでは、Google Analyticsを使用してアクセス状況を分析しています。
5. 当サイトでは、ユーザーからの個人情報の開示・訂正・削除等の請求があった場合、適切に対応いたします。
6. 当サイトは、個人情報に関する法令を遵守し、本ポリシーの内容を適宜見直し、改善に努めます。

### Cookieについて

このサイトでは、Google Analyticsを利用してアクセス状況を分析し、サイトの改善に役立てています。それ以外の方法でユーザーの情報を取得することはありません。
