# 主な掲載コンテンツ

Site for Trainの主なコンテンツと特徴です

## 海外の鉄道

Site for Trainには頻繁に海外を訪れる著者がいます。　日本と海外の鉄道事情の比較、面白いルールといったコンテンツを日本でも世界でもどこにいても読むことができます。

## 鉄道の雑学

鉄道愛好家と聞くとこの内容を思い浮かべられる方も多いのではないでしょうか。　実は、あまり鉄道に興味のない方でも、知っておくと思わぬところで得する面白い情報や、普段の生活を支える鉄道、少々ニッチですが思わず読んでしまう記事がたくさんあります。

## 日本国内の鉄道旅行

日本国内で著者が訪れた観光場所をブログ記事で簡単にご紹介します。できるだけ、写真を多く掲載することを意識しているので、全体的に読みやすく、イメージの膨らませやすい記事になっています。
