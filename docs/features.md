# コンテンツに関して

## このサイトの特徴

このサイトには主に３つの特徴があります。

### 記事がたくさん

思いつきでランダムなタイミングで気が向くままに記事を書いていくので、鉄道に関することでも内容は様々。　鉄道に関する雑学、最近思ったことがメインです。　列車に乗っているとき、暇なとき、トイレでやることがないときなどのおともとしてご活用ください。

### このサイトはなんですか？

鉄道に関するサイトです。

### 週２回更新

週２回ほどの更新なので、鉄道初心者の方でも飽きることなく、とはいえ忘れることがないくらいのちょうどよい頻度で記事を更新します。　ぜひご期待ください。(２回はあくまで目安です)

このサイトはVitepressを利用して、作成しています。　閲覧環境及び動作要件はVitepressの動作するブラウザを使用することが前提となります。

このサイトに掲載してある記事は、筆者が独自に収集した内容を含んでいることがあります。　そのことをご承知の上でご覧ください。 詳細に関してはこのサイト/ブログの最後のセクションにある「このサイトについて」をご覧ください。
