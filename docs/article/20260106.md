# 快速みえに乗った話

## はじめに

この冬休みに、私は家族で伊勢・鳥羽へ旅行に行った。この時に鳥羽〜松阪間で快速みえに乗車したので、その時のことを書いていこうと思う。

## 鳥羽〜二見浦

鳥羽駅にてきっぷを購入。松阪まで 680 円。思ったより安い。

![切符の写真](/photos/20260116-1.jpg)

1号車に乗車。

![快速みえの写真](/photos/20260116-2.jpg)

座席はクロスシート。ふかふかで座り心地は良好。

発車してからすぐは時々海を臨みながら近鉄と並走。別れてすぐに、息を呑む光景が姿を現した。

湾をショートカットするように橋が渡されていて、そこを列車が通っていたのだ。つまり、右も左も海ということだ

![海の写真](/photos/20260116-4.jpg)

奥の方に網のようなものが見える。伊勢志摩という地域の特性上、何かしらの養殖だろう。

この後は、基本内陸中心を走っていく。

![平野の景色](/photos/20260116-6.jpg)
