# 日本の米軍石油輸送列車（前編）

::: details 目次
[[TOC]]
:::

東京都にある米軍基地「横田基地」から横浜にある米軍関連施設まで、石油を輸送する専用貨物列車、通称「米タン」。米軍専用の航空燃料を運ぶためだけに設定された、日本で唯一無二の臨時貨物列車です。今回はたまたまその運行日に遭遇することができたので、その運用を見ていきましょう。

## 「米タン」とは

米タンは東京都の多摩地域に位置している**在日米軍横田基地**へのジェット燃料の輸送に特化した貨物列車のことです。神奈川県横浜市にあるJR鶴見線の安善駅付近にある在日米軍**鶴見貯油施設**からJR鶴見線、南武線などを経由しての輸送が行われているようです。現在は臨時列車となっているようで荷主の米軍の都合によって運行される日が決定されているそうです。

## 実際に見に行きました

2021年4月1日木曜日に貨物列車の撮影をしていたタイミングで、たまたま米タンに遭遇したので実際に安善駅付近での入れ替えの様子を見に行きました。

### JR南武支線八丁畷駅にて

八丁畷駅にて貨物列車の撮影をしていたところ、突如として米タンが現れました。タンク車自体にその車両の常備駅が描かれていますが、そこに安善駅と書かれていたことと**JP-8**と書かれた在日米軍に貸し出されているタンク車独特の表記を発見したことで、その列車が米タンであることがわかりました。

![八丁畷駅で撮影されて貨物列車の写真](/photos/20260404-2.png)

### JR鶴見線浜川崎駅にて

その後、米タンの勇姿を撮影すべく、浜川崎駅まで先回りしました。米タンは、浜川崎駅にて機関車の付け替えや作業員の乗車といった運転の都合上の停車時間がある程度確保されているようで、先回りは比較的容易にできました。鶴見線浜川崎駅では、普段列車が通らない線路部を通るので見応え十分です。

![浜川崎駅鶴見線ホームで撮影されて貨物列車の写真](/photos/20260404-3.png)
