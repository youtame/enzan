## How to execute

1. clone github's repository
    ```bash
    cd ~/dev
    git clone git@github.com:youtame/enzan.git
    ```

2. build docker container
    ```bash
    cd ~/dev/enzan
    docker compose up -d --build
    ```

3. visit your site
    [http://localhost:40050](http://localhost:40050 "http://localhost:40050")
